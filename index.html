On iPhone: play the 24 hands here. At the end, tap Export hand history → Save to Files, then attach the file in Grok Bot chat. You can also tap Export at the top at any time.

The button is drawn at random. Each seat is labeled with its position (BTN, SB, BB, UTG, and so on). After every hand the table pauses with the board, any showdown or all-in cards, and the result — click Next hand to continue. After hand 24 the session-end screen appears and the hand history is offered as a download, a Copy hand history button, and a text box you can select and paste into chat. To save files onto this PC, open this page in Chrome or Edge, click Save to folder once, and pick Documents\PokerLogs. There is no mid-session coaching.

When the session ends, the player first tries to write the JSON into the folder you chose with Save to folder (the directory handle is remembered in this browser). If no folder is set, it falls back to the file picker, then to a normal download (for example gdr25-hand-history.json, or a timestamped name if you did not set a session number). A copy is also stored in this browser as a backup. If the download is blocked — as it is inside a chat file preview — a banner will tell you to open the file in Chrome or Edge; use Copy hand history, or select the JSON in the text box and paste it into chat. The file has every action, every street, every player’s hole cards, the stacks, and the exact menu you were shown at each of your decision points. The import script turns it into the same session state the blinded review already reads from a gdrNN_fast.json file, then one review pass grades it and appends it once to the quality ledger. The player itself never touches the ledger.
